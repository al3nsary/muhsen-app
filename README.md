# تطبيق مُحسن — الميدان

تطبيقٌ واحدٌ ورابطٌ واحد. والدورُ يُقرأ من الحساب بعد الدخول:
الليدرُ يرى شاشاتِه والمُحسنُ يرى شاشاتِه، والشريطُ يتبدّل معهما.

## البناء

```
cd app
node build.cjs
```

## اللغات

ثلاثٌ دائمًا: العربيّةُ والإنجليزيّةُ والملايويّة. والعربيّةُ في
الشيفرة **هي المفتاح** — لا رموزَ ترجمة.

```
node i18n-scan.cjs        # ما لم يُترجَم بعد
node i18n-merge.cjs       # توليدُ 21-dict.js من i18n/bNN.json
```

المعجمُ **مولَّد**: يُحرَّر في `i18n/bNN.json` لا في `21-dict.js`.

## الحرّاس التسعة

يسقط البناءُ إن سقط أحدُها. وكلُّ واحدٍ منها وُلد من علّةٍ وقعت:

| الحارس | ما يمنعه |
|---|---|
| النحو | سكربتٌ لا يُقلع |
| الأسماء العامّة | `top` و`name` وأخواتُهما تُسقط السكربت كلَّه |
| تكرار الدوالّ | آخرُ تعريفٍ يكسب صامتًا |
| الشاشات | وجهةٌ في المُوجِّه بلا دالّة |
| وجهات الشريط | زرٌّ يقود إلى لا شيء |
| الأنماط | CSS بعد `</style>` يظهر نصًّا خامًا |
| المعجم | لغةٌ نُسيت في تعديل |
| الشريط | عودةُ الانزلاق — شيفرةً أو نمطًا |
| حاوية التمرير | شاشةٌ خارج `.view` لا تتمرّر |

## القياس

```
node phone.cjs <muhsen|leader> <ar|en|ms> 390 <وجهة> <meas|shot> [حالة]
```

Chrome لا يُنزل نافذته تحت ٥٠٠ بكسل، فالقياسُ في إطارٍ بعرض الجهاز.
والحالاتُ: `more` · `ride` · `open` · `transit`.

## التجربة محلّيًّا

```
node serve.cjs            # http://localhost:8787/
```
