# تطبيق مُحسن

تطبيق الميدان لفريق **مُحسن** — نموذج تفاعلي كامل بدورين: المحسن الليدر والمحسن.
يعمل بلا خادم وبلا إنترنت، ويُثبَّت على الجوال كتطبيق.

**الرابط المباشر:** يُحدَّث تلقائيًا مع كل تعديل — انظر GitHub Pages في إعدادات المستودع.

---

## ما بداخل المشروع

| المجلد | المحتوى |
|---|---|
| `app/` | الشيفرة المصدرية — تُبنى إلى ملف واحد |
| `docs/` | المخرجات المنشورة (مصدر GitHub Pages) — **لا تُعدَّل يدويًا** |
| `spec/` | التوثيق: قواعد النظام · سجل التعديلات · سجل المهارات |
| `concept/` | تصوّر التصميم الأولي |
| `design/` | مراجع العميل: خطة الحج وشرائحها |

## البناء

```bash
cd app
node build.cjs      # يبني muhsen-app.html و docs/index.html
node smoke.cjs      # ٣١ اختبارًا لدورة العمل كاملة
```

لا يحتاج المشروع أي تثبيت — Node.js وحده يكفي، بلا حزم خارجية.

### حرّاس البناء

أداة البناء توقف الإصدار عند ثلاثة أخطاء قاتلة:

1. **خطأ نحوي** في الجافاسكربت
2. **تصادم أسماء عامة** مع أسماء محجوزة في المتصفح مثل `top` و`history`
3. **شاشة مسجّلة في المُوجِّه وغير معرَّفة** فعلًا

## البيانات

مأخوذة من نظام `Muhsen Activity V2.3` وأُعيدت صياغتها:
٤٧ نشاطًا · قوالب المهام الفرعية · ثلاث جهات (بعثات وشركات) · ثلاثة قادة و١٦ محسنًا · ١٥ تذكرة.

الحالة تُحفظ في `localStorage`، ولها رقم إصدار يعيد التهيئة تلقائيًا عند تغيّر البنية.
**شاشة التحكم** داخل التطبيق تتيح تعديل المواعيد وإضافة مهام وتقديم الوقت وإعادة الضبط الكامل.

## القواعد الأساسية

محسن واحد لكل مجموعة · لا مجموعة فارغة عند البدء · التسكين لكل مهمة على حدة ·
نافذة التحضير ساعتان · نطاق إثبات الحضور ٢ كم · إسناد صلاحية الليدر **للشركات فقط**.

التفصيل الكامل في [`spec/SYSTEM.md`](spec/SYSTEM.md).
